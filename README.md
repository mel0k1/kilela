# Килела

Маленькая браузерная игра про пони в духе Pony Town: гуляй по тёплому миру,
сиди на траве, ложись в солнышко, танцуй и настрой свою пони — гривы, хвосты,
крылья, рожки, шляпы, шарфы, сумки, выражения морды и кьютимарки.

Персонажи нарисованы настоящими спрайтами Pony Town и собираются послойно,
как в оригинале: тело, голова, гривы в три слоя, хвост, копыта, глаза с
зрачками и ресницами, морды, румянец, кьютимарка. Переходы «стоя — сидя»,
«сидя — лёжа» и обратно играются плавными анимациями, точно как в Pony Town.

## Возможности

- четыре локации: Солнечный луг, Туманный лес (с туманом), Снежные пики (со снегом)
  и Кристальные пещеры — пещерный мир со стенами из атласа Pony Town, каменным полом,
  подземным озером, кристаллами и светящимися фонарями;
- мир на настоящих тайлах Pony Town (32×24): трава, песок, вода с анимацией,
  деревянные мостики, снег и лёд — тайлы склеиваются автотайлами, как в оригинале;
- деревья, кусты и камни из атласов Pony Town;
- украшения из атласов PT: заборы (летние, деревянные, зимние и каменные), скамейки,
  бочки, ящики, знаки, цветочные поляны и снегопони;
- вход в пещеры — шахта на Солнечном лугу;
- препятствия одинаковы для всех: генерация мира (рельеф, стены, декор, деревья)
  считается одним общим кодом на клиенте и сервере, сервер проверяет каждый шаг
  и не пускает в воду, стены и сквозь деревья с заборами;
- плавать нельзя: вода непроходима, пруды обходятся по берегу;
- порталы между локациями с плавным затемнением;
- день и ночь, закаты и рассветы — полный цикл за шесть минут;
- чат с баблами над пони и счётчиком игроков;
- эмоции-действия: взлететь/приземлиться, сесть/встать, лечь/встать, танец,
  «копыто» (boop) и объятия;
- полёт: пони с крыльями взлетает кнопкой 🪽, машет крыльями и покачивается в воздухе,
  летает быстрее ходьбы и перелетает воду, декор и деревья (в пещерах летать нельзя);
- одиннадцать выражений морды: удивление, восторг, смех, «ням-ням», зевота, язык, грусть, злость, подмигивание, умиление;
- эмоции-картинки над головой из PSD-исходников PT: сердечки, слёзы, плач, чих
  и «Zzz» во сне — как в оригинале;
- моргание, случайное у каждой пони;
- редактор внешности с живым превью: окрас, гривы и хвосты (около 30 стилей),
  двухцветные пряди, задняя грива, крылья пегаса, все рога из атласа PT,
  копыта, ушки, бородки, головные уборы, шарфы и жилетки, сумки, носочки,
  рукава, пояса и юбки, шейные платки, выбор морды и рта — всё из атласов Pony Town;
- цвет и форма глаз, ресницы, выражение морды, 24 кьютимарки с выбором цвета и отражением;
- бот Искорка на лугу — гуляет и болтает;
- музыка из Pony Town (Wandering Artist) с плейлистами по локациям —
  треки тасуются и сменяются с плавным затуханием, как в оригинале.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev:server
```

Во втором терминале:

```bash
npm run dev:client
```

Открой `http://localhost:5173`. Клиент стучится в WebSocket по адресу `/ws`
того же хоста (прокси прописан в `vite.config.ts`).

Продакшен-сборка клиента:

```bash
npm run build
```

Проверка типов во всех пакетах:

```bash
npm run typecheck
```

## Как играть

- `WASD` или стрелки — ходьба (поддерживается и латиница, и ЦФЫВ);
- клик по земле — пони сама найдёт дорогу в обход воды и деревьев;
- `Enter` — чат;
- кнопки справа внизу — эмоции и выражения морды;
- «Внешность» в верхней панели — редактор пони.

## Структура

```
shared/    протокол, карты и генерация мира (общие для клиента и сервера)
server/    игровой сервер: комнаты, порталы, коллизии, бот, рассылка позиций
client/
  src/pony/   рендер пони на спрайтах Pony Town:
              батч с палитровым перекрашиванием, сборка слоёв,
              кэш отрисованных кадров, анимации и переходы
  src/world/  тайлы, деревья, туман, снег, день/ночь, порталы
  src/game/   сетевая логика, ввод, движение
  src/ui/     вход, редактор внешности, HUD
```

## Технологии

- PixiJS 8 (WebGPU/WebGL) для мира;
- canvas-батч с палитровым перекрашиванием спрайтов — порт подхода Pony Town;
- Node.js + ws для сервера, без базы данных;
- TypeScript, Vite, npm workspaces.
